# Regression Suite

Run the full regression suite with:

`npm run test:regression`

Run the regression suite in headed mode with:

`npm run test:regression:headed`

Folder layout:

- `auth/` for login and access regression coverage
- `patients/` for patient header validation stories
- `employer/` for employer tab positive and negative regression coverage
- `insurance/` for insurance tab positive and negative regression coverage

Useful commands:

- `npm run test:functional`
- `npm run test:functional:headed`
- `npm run test:regression`
- `npm run test:regression:patients`
- `npm run test:regression:patients:positive`
- `npm run test:regression:patients:negative`
- `npm run test:regression:employer`
- `npm run test:regression:employer:positive`
- `npm run test:regression:employer:negative`
- `npm run test:regression:insurance`
- `npm run test:regression:insurance:positive`
- `npm run test:regression:insurance:negative`
- `npm run test:regression:auth`
- `npm run test:regression:auth:positive`
- `npm run test:regression:auth:negative`
- `npm run report:open`
- `npm run test:regression:report`
